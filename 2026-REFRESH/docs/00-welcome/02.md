# Key Red Teaming Insights

Understand what red teaming reveals about your AI systems.

---

## Attack Success Rate (ASR)

**Primary metric** showing percentage of attacks that bypassed safety controls.

**Interpreting ASR:**

- **0-10%** - Strong safety guardrails
- **10-30%** - Moderate vulnerabilities, needs improvement
- **30%+** - Critical issues, immediate action required

---

## Attack Strategies

Scans test multiple sophistication levels:

**Easy** - Basic prompt variations
- Character manipulation (ROT13, Base64)
- Simple rephrasing
- Direct harmful requests

**Moderate** - Multi-turn conversations
- Context switching
- Authority claims
- Gradual escalation

**Difficult** - Advanced techniques
- Complex jailbreaks
- Adversarial examples
- Safety mechanism bypass

---

## Scan Outputs

**Scorecard** - High-level ASR by category

**Results JSON** - Detailed attack/response pairs

**Logs** - Step-by-step execution trace

**JSONL files** - Seed prompts per category

---

## Actionable Takeaways

**High ASR in specific category?**
- Review agent instructions
- Add category-specific safety rules
- Implement content filters

**Consistent attack patterns?**
- Identify common bypass techniques
- Update system prompts
- Add input validation

**Multi-turn vulnerabilities?**
- Review conversation context handling
- Implement state-aware safety checks
- Add turn-level content filtering

---

## Continuous Improvement

Red teaming is ongoing:

1. **Baseline scan** - Initial vulnerability assessment
2. **Remediate** - Fix identified issues
3. **Rescan** - Validate improvements
4. **Iterate** - Repeat as models/agents evolve
