## Configure Red Team Agent

**Initialize with project credentials:**

```python
red_team = RedTeam(
    azure_ai_project=project_endpoint,
    credential=DefaultAzureCredential()
)
```

## Create Agent Callback

**Define callback function for agent testing:**

```python
def agent_callback(query: str) -> str:
    thread = project_client.agents.create_thread()
    
    message = project_client.agents.create_message(
        thread_id=thread.id,
        role="user",
        content=query
    )
    
    run = project_client.agents.create_run(
        thread_id=thread.id,
        agent_id=agent.id
    )
    
    # Wait for completion
    while run.status in ["queued", "in_progress"]:
        time.sleep(1)
        run = project_client.agents.get_run(thread.id, run.id)
    
    messages = project_client.agents.list_messages(thread.id)
    return messages.data[0].content[0].text.value
```

---

## Run Security Scan

**Execute automated red teaming:**

```python
result = await red_team.scan(
    target=agent_callback,
    risk_categories=[RiskCategory.Violence],
    num_objectives=2,
    attack_strategies=[AttackStrategy.EASY]
)
```

**Parameters:**
- `target` - Your agent callback function
- `risk_categories` - Which risks to test (Violence, Sexual, Hate, Self-Harm)
- `num_objectives` - Attack prompts per category (default: 10)
- `attack_strategies` - Sophistication level (EASY, MODERATE, DIFFICULT)

## Review Results

**Scan outputs saved to:** `.scan_YYYYMMDD_HHMMSS/`

**Key files:**

- `scorecard.txt` - Attack success rate summary
- `results.json` - Detailed attack/response pairs
- `redteam.log` - Execution trace
- `*.jsonl` - Seed prompts per category
