# Understanding Agent Scan Results

Learn what agent scan results reveal about security vulnerabilities.

---

## Agent-Specific Risks

Agents with RAG face unique challenges:

**Data leakage** - Adversaries may extract sensitive documents

**Tool misuse** - Attackers could manipulate function calling

**Context manipulation** - Multi-turn attacks exploit conversation state

**Grounding failures** - Agent may ignore retrieval context

---

## Analyzing ASR by Component

**High ASR = Weak point identified**

**Agent instructions** - If ASR is high:
- Add explicit safety rules
- Define prohibited topics
- Include escalation procedures

**RAG context** - If attacks succeed:
- Review document content
- Filter sensitive information
- Add metadata controls

**Tool definitions** - If tool misuse occurs:
- Add parameter validation
- Restrict tool permissions
- Implement approval workflows

---

## Multi-Turn Vulnerabilities

**Pattern: Low ASR in single-turn, high in multi-turn**

**Root cause:**
- Safety checks only on first message
- Context window dilutes safety instructions
- Gradual escalation bypasses filters

**Solutions:**
- Apply content filtering per turn
- Refresh safety instructions periodically
- Implement conversation-level monitoring

---

## RAG-Specific Issues

**Document injection attacks:**
- Adversaries craft queries to retrieve specific docs
- Agent reveals sensitive business information

**Mitigation:**
- Implement access control on documents
- Add metadata-based filtering
- Monitor retrieved context

**Grounding violations:**
- Agent ignores retrieved context
- Makes up information not in documents

**Mitigation:**
- Strengthen grounding instructions
- Add citation requirements
- Validate response against sources

---

## Comparing Attack Strategies

**EASY (10-20% ASR typical):**
- Basic character encoding
- Simple rephrasing
- Direct harmful requests

**MODERATE (20-40% ASR typical):**
- Multi-turn escalation
- Authority claims
- Context switching

**DIFFICULT (30-60% ASR typical):**
- Advanced jailbreaks
- Adversarial examples
- Complex bypass techniques

**Key insight:** Higher ASR with advanced strategies is expected. Focus on reducing ASR for EASY attacks first.

---

## Action Items

1. **Review high-ASR categories** - Prioritize based on business risk
2. **Update agent instructions** - Add safety rules for vulnerable areas
3. **Implement content filters** - Apply Azure AI Content Safety
4. **Re-scan after changes** - Validate improvements
5. **Monitor in production** - Continuous security posture
