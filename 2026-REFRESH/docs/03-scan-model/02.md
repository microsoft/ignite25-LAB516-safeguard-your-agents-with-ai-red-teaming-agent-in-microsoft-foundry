# Understanding Model Scan Results

Learn what model scans reveal about base safety capabilities.

---

## Why Scan Models Directly

**Before adding agent layer:**
- Understand baseline model safety
- Compare models during selection
- Identify which models need strongest safety wrappers

**Base model ASR patterns:**
- GPT-4: Typically 10-20% ASR
- GPT-3.5: Typically 20-40% ASR
- Older models: May exceed 50% ASR

---

## Baseline vs. Strategy Scans

**Baseline scan:**
- Direct harmful requests
- No encoding or obfuscation
- Tests model's refusal training

**Strategy scan:**
- Applies attack sophistication
- Tests bypass techniques
- Reveals vulnerabilities in safety alignment

**Expected pattern:**
```
Baseline ASR: 15%
EASY ASR: 25%
MODERATE ASR: 35%
DIFFICULT ASR: 50%
```

**Key insight:** Gap between baseline and strategy ASR shows how easily model safety can be bypassed.

---

## Fixed vs. Dynamic Callbacks

**Fixed response callback:**
```python
def fixed(query):
    return "I cannot help with that."
```
- Always returns same text
- ASR should be 0%
- Validates scan setup works

**Dynamic response callback:**
```python
def dynamic(query):
    return model.generate(query)
```
- Generates unique responses
- ASR reflects actual vulnerabilities
- Shows real-world risks

**Use both:**
1. Run fixed callback to validate setup
2. Run dynamic callback to measure risk

---

## Attack Strategy Selection

**Start with EASY:**
- Fast execution (fewer prompts)
- Identifies obvious vulnerabilities
- Good for iterative testing

**Add MODERATE for production:**
- Tests multi-turn resilience
- Catches context manipulation
- Balances coverage and speed

**Use DIFFICULT selectively:**
- Comprehensive security assessment
- Pre-deployment validation
- High-risk applications only

---

## Risk Category Prioritization

**Not all categories are equal risk:**

**High priority for most apps:**
- Violence (direct user harm)
- Hate & Unfairness (legal/compliance)

**Medium priority:**
- Sexual (brand risk, age restrictions)

**Context-dependent:**
- Self-Harm (critical for health/mental health apps)

**Scan strategy:**
1. Start with high-priority categories
2. Fix vulnerabilities found
3. Expand to full category set

---

## Comparing Targets

**Same model, different wrappers:**

```python
# Base model scan
base_result = await red_team.scan(target=model_config)
# ASR: 35%

# With safety wrapper
wrapper_result = await red_team.scan(target=safe_callback)
# ASR: 15%
```

**Key insight:** ASR reduction shows wrapper effectiveness.

**Ideal pattern:**
- Base model: Higher ASR (20-40%)
- With agent instructions: Lower ASR (10-20%)
- With content filtering: Lowest ASR (5-10%)

---

## Action Items

1. **Establish baseline** - Scan base model to understand starting point
2. **Add safety layers** - Implement instructions, filters, validation
3. **Re-scan after changes** - Measure improvement
4. **Compare strategies** - Understand which attacks succeed
5. **Document patterns** - Track common bypass techniques for your model
