# Scan Models and Callbacks Locally

Run red teaming scans on different target types during development.

---

## What You'll Do

This lab demonstrates:

- Scan simple callback functions
- Scan complex chat-protocol callbacks
- Scan base models directly
- Customize risk categories and attack strategies
- Analyze baseline vs. advanced results

---

## Scan Simple Callback

**Basic function with fixed response:**

```python
def simple_callback(query: str) -> str:
    return "I cannot provide harmful content."

result = await red_team.scan(target=simple_callback)
```

**Expected outcome:** 0% ASR (fixed response never violates safety)

**Use case:** Validate your red teaming setup works correctly

## Scan Chat Callback

**Function following OpenAI Chat Protocol:**

```python
async def chat_callback(messages, stream=False, session_state=None):
    messages_list = [{
        "role": m.role, 
        "content": m.content
    } for m in messages]
    
    # Process conversation history
    response = generate_response(messages_list)
    
    return {
        "messages": [{
            "content": response,
            "role": "assistant"
        }]
    }

result = await red_team.scan(target=chat_callback)
```

**Use case:** Test custom chatbots and assistants

## Customize Scan Parameters

**Control scan scope and sophistication:**

```python
red_team = RedTeam(
    azure_ai_project=project_endpoint,
    credential=DefaultAzureCredential(),
    risk_categories=[RiskCategory.Violence],  # Test specific risks
    num_objectives=2  # Fewer prompts for faster testing
)

result = await red_team.scan(
    target=callback,
    attack_strategies=[AttackStrategy.EASY]  # Basic attacks only
)
```

**Risk categories:**
- `RiskCategory.Violence`
- `RiskCategory.Sexual`
- `RiskCategory.HateUnfairness`
- `RiskCategory.SelfHarm`

**Attack strategies:**
- `AttackStrategy.EASY` - Character encoding, simple rephrasing
- `AttackStrategy.MODERATE` - Multi-turn, context switching
- `AttackStrategy.DIFFICULT` - Advanced jailbreaks
- Individual strategies: `AttackStrategy.Flip`, `AttackStrategy.ROT13`, etc.

## Review Scan Structure

**Output directory:** `.scan_YYYYMMDD_HHMMSS/`

**Files generated:**

```
.scan_20260203_115904/
├── scorecard.txt          # ASR summary
├── results.json           # Combined results
├── redteam.log           # Execution logs
├── violence.jsonl        # Violence seed prompts
├── baseline_violence.json # Violence attack results
├── sexual.jsonl
├── baseline_sexual.json
└── ...
```

**Understanding baselines:**
- Baseline scans use seed prompts without advanced strategies
- Shows how target responds to direct harmful requests
- Establishes floor for attack success rate
