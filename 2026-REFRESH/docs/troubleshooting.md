# Troubleshooting

## 1. Setup Project

**Issue**: Can't create project in selected region  
**Solution**: Ensure you selected a red teaming-enabled region (East US, West US, West Europe, Sweden Central)

**Issue**: Model deployment fails  
**Solution**: Check your subscription quotas and ensure you have available quota for GPT-4 deployments

**Issue**: Agent doesn't respond as expected  
**Solution**: Verify the instructions were pasted correctly and the model deployment is selected

**Issue**: Don't see "New Foundry" toggle  
**Solution**: You may already be in the new experience. Look for modern UI elements and "Build" tab in left navigation
