## Fix Issues

**Missing environment variables?**
- Re-run setup script
- Check Azure CLI login (`az login`)
- Verify resource exists in portal

**Package errors?**
- Install requirements: `pip install -r requirements.txt`
- Use Python 3.10-3.12 (PyRIT requirement)

**Authentication failures?**
- Run `az login` and sign in
- Verify subscription access
- Check resource permissions

1. Check the error messages in the notebook output
2. Verify resources exist in Azure Portal
3. Re-run the setup script if needed
4. Use **GitHub Copilot** to troubleshoot specific errors
