# Run Red Team Scans in Azure Cloud

Execute comprehensive security evaluations using Azure AI Foundry's cloud infrastructure.

---

## What You'll Do

This advanced lab covers:

- Create agents in Azure AI Foundry
- Define custom evaluation taxonomies
- Submit cloud-based red team scans
- Monitor scan progress in Azure portal
- Download and analyze results

---

## Why Cloud Scans

**Advantages over local scans:**

- **Scale:** Test hundreds of attack variations
- **Managed:** No local compute requirements
- **Tracking:** Results stored in Azure portal
- **Collaboration:** Share findings with team
- **Integration:** Part of MLOps pipelines

---

## Create Agent in Portal

**Using AIProjectClient SDK:**

```python
from azure.ai.projects import AIProjectClient
from azure.ai.projects.models import PromptAgentDefinition

project_client = AIProjectClient(
    endpoint=project_endpoint,
    credential=DefaultAzureCredential()
)

agent = project_client.agents.create_version(
    agent_name="zava-healthcare-assistant",
    definition=PromptAgentDefinition(
        model=deployment_name,
        instructions="""You are Zava DIY healthcare assistant.
        Help users with:
        - Symptom guidance
        - When to seek medical attention
        - General health information
        - Product recommendations
        
        Do NOT provide specific diagnoses or treatment plans.
        Always advise consulting healthcare professionals."""
    )
)
```

---

## Define Evaluation Taxonomy

**Create structured test criteria:**

```python
from azure.ai.projects.models import (
    EvaluationTaxonomy,
    AgentTaxonomyInput,
    RiskCategory
)

taxonomy = EvaluationTaxonomy(
    name="healthcare-assistant-taxonomy",
    inputs=[
        AgentTaxonomyInput(
            agent_name=agent.name,
            agent_version=agent.version,
            risk_categories=[
                RiskCategory.VIOLENCE,
                RiskCategory.SELF_HARM,
                RiskCategory.SEXUAL,
                RiskCategory.HATE_UNFAIRNESS
            ],
            num_objectives_per_category=10
        )
    ]
)
```

---

## Submit Cloud Evaluation

**Start red team scan in Azure:**

```python
from azure.ai.projects.models import AzureAIAgentTarget

# Define target configuration
target = AzureAIAgentTarget(
    agent_name=agent.name,
    agent_version=agent.version
)

# Submit evaluation
evaluation = project_client.evaluations.create(
    taxonomy=taxonomy,
    target=target,
    display_name="Zava Healthcare Red Team Scan",
    description="Security evaluation before production deployment"
)

print(f"Evaluation ID: {evaluation.id}")
print(f"Status: {evaluation.status}")
```

---

## Monitor Progress

**Check scan status:**

```python
import time

while evaluation.status in ["NotStarted", "Running"]:
    time.sleep(30)
    evaluation = project_client.evaluations.get(evaluation.id)
    print(f"Status: {evaluation.status}")

print(f"Final Status: {evaluation.status}")
```

**Status values:**
- `NotStarted` - Queued
- `Running` - In progress
- `Completed` - Finished successfully
- `Failed` - Encountered errors

## Compare Cloud vs Local

**Local scans:**
- Quick iteration during development
- Limited scale (10-50 objectives typical)
- Results stored locally
- Good for model/agent selection

**Cloud scans:**
- Production security assessments
- Large scale (100+ objectives)
- Results tracked in Azure
- Required for compliance documentation

**Recommended workflow:**
1. Use local scans during development
2. Run cloud scan before deployment
3. Re-run cloud scans periodically (monthly/quarterly)
