# Safeguard your agents with AI Red Teaming Agent in Microsoft Foundry

This folder contains a refreshed version of the lab originally delivered at Microsoft Ignite 2026. It has been simplified and updated _in preparation for migration to the Models For Beginners repository as a standalone module_.

## 1. Getting Started

Before you can get started, you need a Foundry Project that has the right resources and permissions setup. You can do this [via the Portal](https://learn.microsoft.com/en-us/azure/ai-foundry/how-to/create-projects?view=foundry&tabs=foundry) or [via the Azure CLI](https://learn.microsoft.com/en-us/azure/ai-foundry/how-to/create-projects?view=foundry&tabs=azurecli) or [via the Python SDK](https://learn.microsoft.com/en-us/azure/ai-foundry/how-to/create-projects?view=foundry&tabs=python) or by using a [the AI Agent Starter Template](https://github.com/Azure-Samples/get-started-with-ai-agents) with a complete solution architecture.

**We'll use the Foundry Portal Today** for both familiarity and convenience. [Complete the steps in this guide](./01-setup-project/README.md) to set this up.
